# VTCA PDF Form > Google Drive

Ứng dụng web đơn giản cho phép học viên:

1. Xem file PDF mẫu "Cam kết hỗ trợ giới thiệu cơ hội việc làm".
2. Điền thông tin vào form tương ứng với các trường trong PDF.
3. Nhấn "Lưu & Gửi lên Google Drive" để:
   - Tự động điền dữ liệu vào các form field trong PDF.
   - Sinh ra file PDF mới.
   - Upload file PDF đã điền vào một thư mục cố định trên Google Drive.

## 1. Yêu cầu

- Node.js 18+
- NPM hoặc Yarn
- Tài khoản Google Cloud + Google Drive API + Service Account

## 2. Cài đặt

```bash
git clone <repo hoặc copy source>
